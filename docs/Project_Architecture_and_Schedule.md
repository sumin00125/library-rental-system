## 2. 프로젝트 구조 설계

### 2.1 전체 시스템 구조

본 프로젝트는 JSP/Servlet 기반 MVC 패턴을 적용하여 구현한다.  
사용자는 JSP 화면을 통해 요청을 보내고, Servlet이 요청을 처리한 뒤 DAO를 통해 데이터베이스와 연동한다. 처리 결과는 다시 JSP 화면에 출력된다.

```text
[사용자]
   ↓
[JSP 화면 - View]
   ↓
[Servlet - Controller]
   ↓
[DAO - Model]
   ↓
[Database]
