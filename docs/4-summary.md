## 4.2 프로젝트 회고

### 잘 된 점

* JSP, Servlet, JDBC를 활용하여 MVC(Model 2) 구조를 적용하였다.
* MySQL 데이터베이스와 연동하여 도서 등록, 조회, 수정, 삭제(CRUD) 기능을 구현하였다.
* 도서 대여 및 반납 기능을 구현하여 실제 도서 관리 시스템과 유사한 환경을 구성하였다.
* Bootstrap 5를 활용하여 사용자 인터페이스를 개선하였다.
* 중복 대여 방지 기능을 추가하여 비즈니스 로직의 완성도를 높였다.

### 아쉬운 점 및 개선 사항

* 로그인 및 권한 관리 기능을 구현하지 못하였다.
* 도서 검색 기능과 페이징 기능을 추가하면 사용자 편의성이 향상될 것으로 생각된다.
* 관리자와 일반 사용자를 구분하는 권한 제어 기능을 추가하면 실제 서비스에 더욱 가까운 시스템이 될 것이다.

### 구현 소감

이번 프로젝트를 통해 JSP, Servlet, JDBC를 이용한 웹 애플리케이션 개발 과정을 경험할 수 있었다. DAO, DTO, Controller, JSP를 연결하는 MVC 패턴을 실제로 적용하면서 웹 프로그래밍의 흐름을 이해할 수 있었다. 또한 AI를 활용하여 반복적인 코드 작성을 효율적으로 수행하고, 발생한 오류를 디버깅하면서 문제 해결 능력을 향상시킬 수 있었다.
