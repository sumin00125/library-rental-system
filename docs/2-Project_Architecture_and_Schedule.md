# 프로젝트 구조 및 역할·일정 관리 계획

## 1. 프로젝트 개요

본 프로젝트는 JSP, Servlet, JDBC, MySQL을 활용하여 개발한 도서 대여 및 재고 관리 시스템이다.

사용자는 등록된 도서의 목록을 조회하고 상세 정보를 확인할 수 있으며, 관리자는 도서 등록, 수정, 삭제 기능을 수행할 수 있다. 또한 도서 대여 및 반납 기능을 제공하며, 이미 대여 중인 도서에 대해서는 중복 대여를 방지하도록 구현하였다.

본 프로젝트는 MVC(Model 2) 패턴을 적용하여 유지보수성과 확장성을 고려한 구조로 설계하였다.

---

## 2. 프로젝트 구조 설계

### 2.1 전체 시스템 구조

본 프로젝트는 MVC 디자인 패턴을 기반으로 구성하였다.

```text
[사용자]
   ↓
[JSP View]

- index.jsp
- bookList.jsp
- bookForm.jsp
- bookDetail.jsp
- rentalForm.jsp
- rentalList.jsp

   ↓ 요청

[Controller]

- BookController
- RentalController

   ↓ 처리 요청

[Model]

- BookDTO
- RentalDTO
- BookDAO
- RentalDAO
- DBConnection

   ↓ DB 처리

[Database]

- book
- rental
```

---

### 2.2 기능 요소 구조

```text
도서 대여 및 재고 관리 시스템
│
├─ 도서 관리
│  ├─ 도서 등록
│  ├─ 도서 목록 조회
│  ├─ 도서 상세 조회
│  ├─ 도서 수정
│  └─ 도서 삭제
│
├─ 대여 관리
│  ├─ 도서 대여
│  ├─ 도서 반납
│  ├─ 대여 상태 조회
│  └─ 중복 대여 방지
│
└─ 데이터 관리
   ├─ MySQL 연동
   └─ JDBC 기반 CRUD 처리
```

---

### 2.3 화면 구조

| 화면       | 주요 기능                  | 관련 요구사항                |
| -------- | ---------------------- | ---------------------- |
| 메인 화면    | 프로젝트 소개 및 메뉴 이동        | 전체                     |
| 도서 목록 화면 | 도서 목록 조회, 상세보기, 수정, 삭제 | F-02, F-03, F-04, F-05 |
| 도서 등록 화면 | 도서 등록                  | F-01                   |
| 도서 상세 화면 | 상세 정보 출력               | F-03                   |
| 대여 등록 화면 | 도서 대여                  | F-06                   |
| 대여 목록 화면 | 대여 목록 조회, 반납 처리, 상태 확인 | F-07, F-08, F-09       |

---

### 2.4 주요 구성 요소와 관계

| 구성 요소        | 역할                   | 관련 기능                    |
| ------------ | -------------------- | ------------------------ |
| JSP          | 사용자 화면 출력 및 입력 폼 제공  | 목록 조회, 등록, 수정, 대여, 반납    |
| Controller   | 사용자 요청 처리 및 화면 이동 제어 | 등록, 수정, 삭제, 상세조회, 대여, 반납 |
| DTO          | 데이터 전달 객체            | 도서 정보, 대여 정보             |
| DAO          | 데이터베이스 처리            | CRUD, 대여/반납 처리           |
| DBConnection | JDBC 연결 관리           | 데이터베이스 연결                |
| Database     | 데이터 저장               | 도서 및 대여 정보 저장            |
