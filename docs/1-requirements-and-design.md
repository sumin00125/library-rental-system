# 요구사항 및 설계 문서

## 1. 프로젝트명

도서 대여 및 재고 관리 시스템 (Library Rental System)

---

## 2. 요구사항

### 2.1 요구사항 개요

본 프로젝트는 도서 정보를 등록하고 관리하며, 도서의 대여 및 반납 상태를 관리할 수 있는 웹 기반 도서 관리 시스템이다.

사용자는 등록된 도서 목록을 조회하고 상세 정보를 확인할 수 있으며, 관리자는 도서 등록, 수정, 삭제 기능을 수행할 수 있다. 또한 도서 대여 및 반납 기능을 제공하며, 이미 대여 중인 도서에 대한 중복 대여를 방지하도록 구현한다.

---

### 2.2 기능적 요구사항

| ID   | 요구사항     | 상세 내용                                                 | 우선순위 |
| ---- | -------- | ----------------------------------------------------- | ---- |
| F-01 | 도서 등록    | 관리자는 도서명, 저자, 출판사, ISBN, 카테고리, 수량을 입력하여 도서를 등록할 수 있다. | 높음   |
| F-02 | 도서 목록 조회 | 사용자는 등록된 도서 목록을 확인할 수 있다.                             | 높음   |
| F-03 | 도서 상세 조회 | 사용자는 특정 도서의 상세 정보를 조회할 수 있다.                          | 높음   |
| F-04 | 도서 정보 수정 | 관리자는 등록된 도서 정보를 수정할 수 있다.                             | 높음   |
| F-05 | 도서 삭제    | 관리자는 등록된 도서를 삭제할 수 있다.                                | 높음   |
| F-06 | 도서 대여    | 사용자는 대여 가능한 도서를 대여할 수 있다.                             | 높음   |
| F-07 | 도서 반납    | 사용자는 대여한 도서를 반납할 수 있다.                                | 높음   |
| F-08 | 대여 상태 확인 | 시스템은 현재 대여 상태 및 반납 여부를 표시한다.                          | 높음   |
| F-09 | 중복 대여 방지 | 이미 대여 중인 도서는 중복 대여할 수 없다.                             | 높음   |

## 3. 시스템 설계

### 3.1 MVC 디자인 패턴

본 프로젝트는 JSP/Servlet 기반 MVC(Model 2) 패턴을 적용하였다.

| 구분         | 역할             | 파일 예시                                                   |
| ---------- | -------------- | ------------------------------------------------------- |
| Model      | 데이터 객체 및 DB 처리 | BookDTO, RentalDTO, BookDAO, RentalDAO                  |
| View       | 사용자 화면 출력      | index.jsp, bookList.jsp, bookDetail.jsp, rentalList.jsp |
| Controller | 요청 처리 및 화면 제어  | BookController, RentalController                        |

---

### 3.2 처리 흐름

1. 사용자가 JSP 화면에서 요청을 보낸다.
2. Controller(Servlet)가 요청을 처리한다.
3. DAO가 데이터베이스에 접근한다.
4. 처리 결과를 반환한다.
5. JSP가 결과를 출력한다.
